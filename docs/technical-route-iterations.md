# Crafter 技术路线迭代与结果：从自然能力诊断到 self-branch

> 更新于 2026-10-13。本文记录已实现或已完成评测的路线；设计提案、工程预检和正式学习效果分开标注。所有 Crafter Score 均来自独立自然场景评测，不用训练回报替代。

## 结论先看

我们最初要解决的是 DreamerV3 在 Crafter 中难以从自然出生学会长链工具技能的问题，尤其是工作台、石镐、煤、熔炉、铁矿和铁镐之间的前置依赖。实验依次从人工辅助出生、H/B 状态预测、行为探索与 Curious Replay 启发回放，走到当前的 self-branch 成功轨迹回放。

目前最有希望扩大验证的是 **scale-v3 branch 数据臂**：从共同的 610k 完整检查点出发，Branch 在 1.5M 的 100 局自然 Score 为 **23.66**，1.3M 峰值为 **24.94**；Source 对照在 1.5M 为 **17.83**，1.37M 峰值 **20.22**。共同 600k baseline 为 **11.87**。Branch 在 1.5M 的自然石镐成功率为 **56/100**，Source 为 **40/100**；两臂铁镐都为 **0/100**。

这说明当前方法在这个训练种子和这一对数据臂上出现了值得继续验证的收益信号，特别是石镐和综合 Score；它**不能**证明跨种子稳定提升、完整铁镐链已解决，或提升必然由 self-branch 机制单独导致。每臂只有一个训练种子，检查点间评测共享同一训练轨迹，分数存在自然波动。

## 1. 任务与测量原则

Crafter 有 22 项成就，Score 将这些成就的获得率汇总为综合指标。高分可能来自较容易的生存和采集成就，不能据此推断石镐或铁镐已经学会。因此路线评估同时看：

- 独立自然回合的 Crafter Score；
- 木镐、采石、煤、熔炉、铁矿、石镐、铁镐、钻石等具体成就成功率；
- 可制作机会中的正确动作、无效制作和重复制作；
- checkpoint 步数、模型哈希、评测种子、逐局结果与逐动作记录。

辅助场景成功只说明策略能在该初始分布下完成目标；它不等于自然出生迁移。训练过程中被强制执行的动作或新解锁也不等于评测策略会自主复现。相关动作诊断见 [铁镐研究路线](ironpick-research-roadmap.md)，长期决策及工程边界见 [工程实践记录](engineering-journey.md)。

## 2. 路线迭代

### 路线 A：自然 Dreamer baseline 与问题定位

先保留自然出生 DreamerV3 模型作为能力和工程基线。600k baseline 的统一自然评测为 100 局、Score **11.86897**。模型有一定综合能力，但高级制作稀少，且训练日志中的制作命令不能区分“当时可做”与“缺材料、缺设施或正在睡眠”。

因此对自然轨迹做了状态—动作对齐与环境重放。一个 10k baseline 续训片段中，石镐有 **493 个清醒且材料、设施可用的机会**，策略只在其中发出 **1 次**石镐指令；铁镐有 **99 个可行机会**，可行时发出 **0 次**目标指令。完整重放核对了图像、奖励、终止和成就，排除了“Crafter 配方坏了”这一简单解释。证据更支持“策略未在可行时机选择目标动作”，但不能单独判定 actor、critic 或世界模型哪一环造成该行为。

### 路线 B：人工辅助出生与多技能课程

早期实验用工作台和木头构造辅助出生，让智能体仍自行探索和选择动作；后续扩展到木镐至钻石的八个目标，并比较固定多技能分配、逐级课程等调度。旧 3×3 汇总曾显示辅助训练对综合 Score 的平均收益，但不同种子波动明显，高阶能力没有稳定解决。后续八技能路线把技能覆盖、前置依赖和退出辅助门槛设计得更完整，但设计本身不能当作已验证收益。

主要教训是：准备好的场景可能教会局部动作，却没有教会自然出生时如何采集材料、识别设施、安排顺序并及时制作。课程同时改了状态分布和奖励时，也不能把最终差异归因于单一机制。旧课程设计和证据边界见 [engineering-journey.md](engineering-journey.md) 与 [current-training-strategy.md](current-training-strategy.md)。

### 路线 C：RA-ACH 设想与 RA-HB v2 实验

RA-ACH 曾设想把成就是否已完成、是否仍可获奖等状态显式作为场景条件；RA-ACH 本身没有正式训练。随后 RA-HB v2 真正实现并训练了另一种方案：策略获得每回合固定初始历史 (H_0)，真实成就历史 (H) 和背包向量 (B) 只作辅助预测损失标签，策略在评测时仍从图像、动作历史和循环状态推断进度。训练混合自然与 A/B 石镐、铁镐准备／制作场景，目标是学习“首次成就”与库存变化，而非直接给专家动作。

在约 300k 停止时，自然评测 20 局 Score **2.698**，木镐、石镐、铁镐均为 **0/20**；A 石镐辅助目标达到 **10/10**，B 铁镐辅助目标 **0/10**。原自然 baseline 的 300k 正式结果为 7.805/100 局，但评测局数和评测集并不严格配对，所以不是精确因果比较。局部 A 成功未迁移，B 也未学会，故停止这条高成本训练。详见 [RA-HB v2 复盘](ra-hb-v2-postmortem.md)。

**判断**：状态预测损失数值稳定不代表策略会使用该状态来规划；固定辅助场景能降低局部任务难度，也可能让模型学到依赖场景分布。该失败不能证明所有课程或状态表征都无效。

### 路线 D：先增加目标动作探索，再测试 Curious Replay

针对可行状态下极少选择目标动作的问题，做了有界行为探索试探：在辅助回合最初 32 步，以 50% 概率覆盖为均匀随机动作，不读取材料、成就或目标标签；策略和测试时不启用覆盖。该 10k 试探在训练中产生了 11 次石镐、3 次铁镐新解锁，对照为 1 次和 0 次，但评测时两组准备场景石镐／铁镐均为 0/30；探索臂自然 Score 11.061，均匀对照 12.230。它确实增加了训练探索，却没有建立可独立复现的策略。

随后保持行为探索与训练预算，加入 Curious Replay 启发的基于逐步世界模型损失和回放次数的优先抽样。CR 臂自然 Score 为 **12.744/30**，均匀对照为 **12.230/30**，但准备石镐和铁镐仍为 **0/30**；CR 训练过程中虽然有目标解锁，也没有通过预设晋级门槛。该实现是 CR-inspired 适配，并非原论文完整复现；一次短程、单起点试验不能否定 Curious Replay。证据见 [CR 接入与效果审查](cr-integration-assessment.md) 和 [CR 轨迹重建](results/cr-exploration-recipe-replay.json)。

**判断**：提高目标动作出现频率，或更频繁重放高模型误差序列，都没有自动教会策略在自然可行状态下制作。错误可能在轨迹覆盖、状态表征、价值估计或 actor 决策；这些机制需要分开诊断。

### 路线 E：self-branch 与 Source 两种成功轨迹回放臂（scale-v3）

#### 共同设置与区别

两臂都从同一个 Dreamer/Curious-Replay 610k 完整检查点恢复，采用自然场景训练，辅助场景权重为零，关闭随机动作覆盖；共享训练种子、配置、目标动作预算与 CR 参数。每臂先续训至 1M，再从各自 1M 状态延长至 1.5M。两臂的核心区别是额外注入的成功轨迹 bank：

- **Branch**：从冻结 610k 策略的成功石镐轨迹中，保留不同分支的完整成功序列。审计覆盖两个地图命名空间，共 26 个完整序列、约 5,881 个转移。成功序列来自受控的分支／执行动作构造和原生环境重放；这不是专家示范数据，也不是最终策略评测成功。
- **Source**：从相同冻结策略在对应地图上取得的源轨迹中，按 Branch 的分支覆盖量做匹配重复，形成约 26 个序列、6,000 个转移。两个 bank 的数据来源和转移重复结构不同；匹配规模旨在让比较聚焦于“多分支覆盖”与“匹配源轨迹重放”的差异。

两臂都使用 CR 回放机制；对照不是“CR 对无 CR”，而是“多分支成功轨迹 bank 对匹配源轨迹 bank”。实验协议和 bank 审计见 [branch protocol](../scripts/scale-v3/student-branch-protocol.json)、[source protocol](../scripts/scale-v3/student-source-protocol.json) 及 [scale-v3 评测表](results/scale-v3-600k-to-1500k/README.md)。

#### 自然评测结果

从 1.01M 到 1.5M，每臂每 10k 检查点进行 100 局自然评测；加上共同 600k baseline 和补测的 pre-1M 幸存检查点，曲线由逐节点记录汇总。Branch 与 Source 的 1M 起点、1.5M 终点及具体技能为：

| 独立自然评测点 | Score / 100 局 | 石镐 | 采集铁矿 | 铁镐 | 采集钻石 |
|---|---:|---:|---:|---:|---:|
| 共同 baseline 600k | 11.87 | 0% | 0% | 0% | 0% |
| Branch 1M | 19.14 | 34% | 1% | 0% | 0% |
| Source 1M | 17.99 | 28% | 4% | 0% | 0% |
| Branch 1.5M | 23.66 | 56% | 10% | 0% | 0% |
| Source 1.5M | 17.83 | 40% | 1% | 0% | 0% |

Branch 在 1M→1.5M 的端点 Score 增加约 **4.52**；Source 变化约 **-0.16**。两个臂的最佳已测 Score 都高于终点：Branch 为 **24.94（1.3M）**，Source 为 **20.22（1.37M）**。这表示 checkpoint 评测会波动，单看最新点或训练回报会误读效果。完整 10k 曲线、分数、成就率、checkpoint agent 哈希与评测目录见 [scores.csv](results/scale-v3-600k-to-1500k/scores.csv) 和 [score-curve.svg](results/scale-v3-600k-to-1500k/score-curve.svg)。

**测量空档**：两臂均从 610k 初始化，但 610k 没有同协议自然评测。610k 至首个幸存的可测节点约 823k（Branch）／827k（Source）之间，早期 checkpoint 已删除，无法补测；曲线如实留白，没有插值。1.5M 前的每个已留存节点有 100 局自然评测。Pre-1M 目前有 31 个幸存 checkpoint 完成 100 局补测。

#### 对 scale-v3 的解释边界

1. Branch 比 Source 终点高 **5.83 Score**，且 1.5M 石镐成功率高 16 个百分点；这是值得复测的机制信号。
2. 两臂各只有一个训练种子，来自相同初始检查点但其后的采样轨迹不同；bank 内容也有意不同。因此结果与 Branch bank 有利相符，但不能排除轨迹随机性，也不能作为多种子因果定论。
3. 两臂 1.5M 铁镐和钻石仍为零，说明自然环境长链铁工具目标没有解决。Branch 的主要可见收益目前集中在综合能力与石镐，不可泛化为整条高阶工具链完成。
4. 600k 基线与两臂 1M、1.5M 的自然评测显示总体能力提高，但不构成同起点、同预算的无干预对照：共同初始化点是 610k，且该点无标准化评测。
5. 结果支持继续做同初始状态、多训练种子、固定评测协议的验证，不支持直接宣称新算法优越或全面解决无效制作。

## 3. 路线结论与后续检验

- **目前最值得继续验证**：Branch 成功多分支 bank。它在统一 1.5M 独立评测里显著领先匹配 Source 臂，石镐收益也与“覆盖不同成功分支”假设一致。
- **当前未解决**：铁镐及铁矿后的完整链条、成功分支对 actor 目标动作概率的因果影响、跨地图和跨训练种子的稳健性。
- **优先实验**：从同一完整起点配对多个训练种子；固定学生交互量、梯度更新数、bank 转移数与 100 局评测，比较自然均匀回放、匹配 Source bank、Branch bank。预注册一个主要终点（自然石镐成功率或综合 Score）和铁镐次要终点，保留全部 checkpoint 曲线。
- **控制复杂度**：先分析 branch bank 是否提高真实可行状态下的制作指令率和首次成功；若有提升再扩充铁镐链。暂不把 H/B 预测、固定辅助课程、重复惩罚、专家演示和 Curious Replay 参数调整重新叠加到同一实验。
