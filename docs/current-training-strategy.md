# 当前训练策略：八技能单目标课程（v5）

这是从零重训的当前工程迭代。下方旧3×3实验属于历史协议，不能用于证明新版奖励/场景的效果。

## 模型和学习
共享同一个DreamerV3模型，利用真实交互和世界模型想象轨迹进行强化学习。
每个辅助回合只有一个统计目标，策略没有目标标签、成就向量或专家动作输入。
准备动作通过原生游戏规则创建库存、工具和真实前置成就，但地形是构造场景；准备成本单独记账，不放入经验池。

## 八项场景
| 目标 | 初始准备 |
|---|---|
| 制作木镐 | 工作台、木头 |
| 采集石头 | 木镐、初始石头0、可采石区域 |
| 制作石镐 | 木镐、工作台、木头1、石头1 |
| 采集煤炭 | 木镐、可达煤矿 |
| 放置熔炉 | 木镐、固定石头4、额外可采石区域与合法放置位置 |
| 采集铁矿 | 石镐、可达铁矿 |
| 制作铁镐 | 木头1、煤炭1、铁1，同时邻近工作台和熔炉 |
| 采集钻石 | 铁镐、可达钻石 |

初始前置成就已经真实解锁，不能重复领赏；目标成就尚未解锁。
初始四石头仅提供一次，用掉后需自己采集；不会自动补材料。
成功只用于统计与调度，不因为成功就中断回合。
局部成功不等于自然出生能完成整条路线。

## 两种调度
- 同批 fixed_multiskill：自然70%，八技能各3.75%，全程固定。
- 逐级 staged_curriculum：木镐 → [采石、煤炭] → [石镐、熔炉] → 铁矿 → 铁镐 → 钻石。
- 并列层级内均分；所有成员通过对应轮次后，前层先释放15%，再次通过后释放剩余15%。
- 每轮门槛需要两次间隔至少20k动作的开发检查，各至少30回合且成功率至少80%，再经独立场景确认。
- 钻石全部门槛完成前自然70%/辅助30%；完成后自然100%/辅助0%。
- 分配按真实交互动作计账，采用2500动作块；短段实际占比有离散误差，固定策略200k新增动作构成精确周期。
- 不进行性能回退，不采用两技能联合完成目标。

## 统一训练奖励
自然出生和辅助出生的训练回合统一只保留八技能以及采木、工作台的成就奖金。
采木和工作台在现有辅助场景中已经作为前置完成，因此也不能再次领赏。
其余12项成就可实际发生并记录，但不发成就奖金；不封禁动作，仍可能消耗材料。
保留原生生命值变化/10；每步最多一个新成就奖金，兼容同一步多个成就。
评测时使用原始自然环境及原始奖励，报告全部22项成就和标准Crafter Score。训练与评测奖励不同会明确标注。
因此新版同时改变初始状态和辅助奖励，不再描述为“只改出生位置”。

## 本次从零训练与证据边界
同批和逐级两组均使用当前自然baseline的训练seed23，以及相同网络和优化器配置。
两组都从随机初始化开始，经验池为空，不加载旧模型、优化器或训练状态。
GPU预检比较两组初始agent状态，并分别验证连续400步与300+100恢复一致性。
目标各400000动作，总800000正式动作；预检1600动作单独记账。
旧212539步续训任务已停止，不再恢复；此前结果保留为历史证据。
相同seed不意味着后续探索轨迹相同；两组场景分配不同，本来就会产生不同数据。
旧自然baseline采用原始奖励，只是工程参照，不能把差异全部归因于课程。
仍只有一个配对训练种子，不能声称跨种子稳定优越。
保留原20k双轮门槛；六层全部退出辅助最快理论需480k，400k是阶段预算，不保证走到最后一层。

## 验证和运行
CPU环境测试通过64种场景组合、304次成功重复前置动作零奖金检查、12类非主线奖金屏蔽及自然轨迹一致性。
从零训练先完成GPU400对300+100恢复一致性检查，两组共1600动作，不计入正式预算。
最多两路训练加一路评估，各独占空闲GPU、2核、20GiB显存和16GiB进程树内存；不足时排队，冲突只停止自己的任务。
每10k保存并进行自然评测：普通节点50回合，50k倍数100回合；每20k八技能各30回合，400k另有独立100自然回合。
自然开发/技能开发/门槛确认/最终留出使用隔离命名空间。CSV保留22项成就、回合数、步骤和模型哈希。
不再产生大量120秒周期checkpoint；每10k段完成时保存，中断最多重做当前段。
只有确认评测写入CSV并核验哈希后才删除中间节点；保留0、50k倍数、实测峰值、未评测与活动恢复/门槛依赖。
已弃用但尚未评测的节点暂留，不能伪造分数或在没有评测证据时删除。
远程管理器负责恢复，本地每30分钟检查一次，正常状态保持静默。
本轮14小时硬截止，连续3次普通失败停止；不自动扩大到400k以上或降低门槛。

v5运行实现及来源锁保留在独立runtime工作区；本说明同步到portable仓库，不表示portable旧入口已包含v5训练器。
